---
command_id: launch:user-directory
---

A macOS game launched from an application bundle without this option writes the player's files to the home directory's `Library/Application Support/siliconsun` folder. The debug log, [out-of-sync reports](/using/out-of-sync-reports/) and [crash reports](/using/crash-reports/) still go into folders beside the executable. [Game data](/using/game-data/) lists the files the directory receives.
