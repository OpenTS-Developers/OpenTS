`2` selects the large-Tiberium overlay set, `3` and `4` select the second and third Tiberium overlay sets, and `1`, or any other value except `-1`, selects the standard Tiberium overlay set. `-1` counts as leaving the key out. Every set has twelve growth stages. Only the large-Tiberium set has no slope overlays, so a type on it never spreads onto a slope and shows nothing on one.
