`Rotor1LandedVoxel` names rotor 1's VXL model for an aircraft at ground level. The engine adds `.VXL` and reads the file only when [`VoxelRotors=yes`](/keys/voxelrotors/) is set. [Aircraft rotors](/systems/aircraft-rotors/#voxel-artwork) explains model selection and fallback.
