when_omitted:

  value: ""

`Rotor3IdleVoxel` names rotor 3's VXL model for an aircraft while idle. The engine adds `.VXL` and reads the file only when [`VoxelRotors=yes`](/keys/voxelrotors/) is set. [Aircraft rotors](/systems/aircraft-rotors/#voxel-artwork) explains model selection and fallback.
