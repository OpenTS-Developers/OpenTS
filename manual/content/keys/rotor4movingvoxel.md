`Rotor4MovingVoxel` names rotor 4's VXL model for an aircraft above ground level, including while hovering. The engine adds `.VXL` and reads the file only when [`VoxelRotors=yes`](/keys/voxelrotors/) is set. [Aircraft rotors](/systems/aircraft-rotors/#voxel-artwork) explains model selection and fallback.
