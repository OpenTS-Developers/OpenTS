[The order of the strips](/systems/sidebar/#the-order-of-the-strips) gives the arrangement this
setting turns on.

The game reads the setting once at startup, and no in-game switch changes it. Turning it off
stops a strip being rearranged from that point on; it does not restore the order a strip already
has, because the order the offers arrived in is not recorded.
