---
type: action
id: TACTION_SET_GROUP_ID
title: Set Group ID
summary: Puts the one object that sprang the trigger into a numbered group.
valid_values:
  - Any number. It is stored as given, with no range check.
caveats:
  - Only the object that sprang the trigger is changed. This is the one action of the attached-object family that does not sweep every tagged object, so a second object with the same tag keeps the group it had.
  - A trigger that sprang from a cell, from a house list or from Force Trigger has no object to work on, and the action then does nothing at all.
  - Only an infantry, vehicle, aircraft or structure is changed. Anything else that sprang the trigger is ignored.
  - The number replaces whatever group the object had, and nothing restores the old one. Objects start out on `-1`.
  - Only `0` through `9` are matched by the player's group hotkeys, and those hotkeys reach only objects the player controls. A number outside that range is stored all the same, and both the wake-up action and team recruitment still match it.
related:
  - type: action
    id: TACTION_WAKEUP_GROUP
  - type: key
    id: Group
    scope: teamtype
  - type: system
    id: ai-team-production
---

Three things act on an object's group. The player's ten group hotkeys select, add to and center on the objects with the matching number, counting from `0` for the first of them. [Wake up group](/mapping/actions/taction-wakeup-group/) puts every sleeping or harmless infantry, vehicle and aircraft with the number it names back on guard. And a computer team [recruits](/systems/ai-team-production/#recruitment) from the objects with its own [`Group`](/keys/group/#scope-teamtype), stamping that group onto each member as it joins, which overwrites whatever this action stored.
