---
type: action
id: TACTION_DISABLE_SHORT_GAME
title: Disable Short Game
summary: Turns the short game rule off, so a house in a skirmish or multiplayer game is defeated only once it has no structures, aircraft, infantry or vehicles left.
caveats:
  - While the harvester truce is on, a house whose only remaining vehicles are harvesters counts as having none.
  - A campaign never applies the rule, so the action changes nothing there.
related:
  - type: action
    id: TACTION_ENABLE_SHORT_GAME
  - type: format
    id: spawn-ini
---
