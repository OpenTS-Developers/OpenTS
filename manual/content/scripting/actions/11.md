---
type: action
id: TACTION_TEXT_TRIGGER
title: Text Trigger...
summary: Prints one numbered line of tutorial text over the tactical view in a chosen color and for a chosen time.
valid_values:
  - The number of a line in the map's `[Tutorial]` section or in `TUTORIAL.INI`.
  - A color's index in the rules' `[Colors]` list.
  - A whole number of seconds for the display time.
caveats:
  - A text line number that neither the map nor `TUTORIAL.INI` holds prints nothing. The trigger's other actions still run.
  - A color's index that does not match any color scheme uses the local player's color.
  - Tutorial lines share the on-screen message list with chat and game notices. The list shows six messages, and each new message after that removes the oldest, so later messages can take the line off the screen before its time is up.
  - A line too wide for the message area is split into several messages. Each part plays the incoming-message sound and can be pushed off the screen separately.
related:
  - type: format
    id: tutorial-ini
  - type: key
    id: MessageDelay
---

The text comes from the numbered lines that [TUTORIAL.INI](/formats/tutorial-ini/) holds. A map can add or replace lines with a `[Tutorial]` section of its own. Its lines take precedence over `TUTORIAL.INI` lines with the same number for as long as the mission is played.

```ini title="TUTORIAL.INI"
[Tutorial]
120=Hold the ridge until the transports arrive.
```

```ini title="map file"
[Tutorial]
120=Hold the bridge instead.
121=Fall back to the ridge.

[Actions]
DemoText=1,11,0,120,0,0,0,0, ; line 120 in the first color, for the MessageDelay time
Brief=1,11,0,121,2,30,0,0,  ; line 121 in the third color, for about 30 seconds
```

The color goes in the first of the four fields after the text line number, and the display time in the second. The last two fields are unused; write `0` for both.

Count the color position from `0`; `0` is the first entry of [`[Colors]`](/keys/color/).

A display time of `0` or less keeps the line on screen for [`MessageDelay`](/keys/messagedelay/). A positive time keeps it for that many seconds. Later messages can still push the line off before that time ends.
