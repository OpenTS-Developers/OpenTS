---
type: action
id: TACTION_TEXT_TRIGGER
title: Text Trigger...
summary: Prints one numbered line of tutorial text over the tactical view.
valid_values:
  - The number of a line the scenario's own `[Tutorial]` section carries, or one from `TUTORIAL.INI`.
caveats:
  - A number neither carries prints nothing at all, and the trigger otherwise runs as normal.
  - The line joins the same list the multiplayer and engine messages use, so enough later messages will take it off the screen before its own time is up.
  - A line too long for the width available is broken and printed as several messages, each with its own lifetime and its own message sound.
related:
  - type: format
    id: tutorial-ini
  - type: key
    id: MessageDelay
---

The text comes from the numbered lines [TUTORIAL.INI](/formats/tutorial-ini/) describes. A mission
prints a line of its own by writing a `[Tutorial]` section into its map, which stands in front of
that file for as long as the mission is played.

```ini title="TUTORIAL.INI"
[Tutorial]
120=Hold the ridge until the transports arrive.
```

```ini title="map file"
[Tutorial]
120=Hold the bridge instead.

[Actions]
DemoText=1,11,0,120,0,0,0,0, ; trigger DemoText prints tutorial line 120
```
