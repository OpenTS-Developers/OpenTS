---
type: action
id: TACTION_CREATE_AUTOSAVE
title: Create Autosave
summary: Saves the game once the current frame has finished.
caveats:
  - Uses the same rotating campaign and skirmish slots as timed autosaves. A multiplayer game writes the multiplayer save file, and writes nothing once a player has left the match.
  - Works even when timed autosaves are disabled. Playback never writes a save.
  - A second request in the same frame shares the first.
related:
  - type: format
    id: save-games
  - type: using
    id: compatibility-and-saves
---

The file is written after the end-of-frame deletion pass retires objects marked for removal.
