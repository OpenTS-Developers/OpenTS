---
type: action
id: TACTION_DELETE_OBJECT
title: Delete Attached Objects
summary: Takes every infantry, vehicle, aircraft and structure the trigger is attached to off the map without destroying it.
caveats:
  - Nothing that follows a destruction follows this. No explosion plays, no kill is recorded, and the object's Destroyed event does not fire.
  - Only an object standing on the map is removed; one carried inside another or still being placed is left alone.
related:
  - type: action
    id: TACTION_DESTROY_OBJECT
  - type: event
    id: TEVENT_DESTROYED
---

The object leaves the map at once and is released at the end of the frame, the way every other retired object is.
