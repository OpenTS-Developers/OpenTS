title: Destroy Trigger
summary: Removes every trigger of the named type from the scenario for good.
valid_values:
  - A trigger type the scenario declares. One trigger is built from it for each tag that holds it, and every one of those is removed.
caveats:
  - Each matching trigger stops springing and firing the moment the action runs, but it is not released until the end-of-frame disposal.
  - A trigger that names its own type here marks the very trigger whose actions are running. The rest of that action list still runs, because the refusal is tested only as firing begins.
  - The tag survives. Only the triggers hanging off it are taken away.

## The tag is left behind

Each trigger unhooks itself from its tag as it is released, moving the tag's link on to the next trigger in the chain. A tag that held a single trigger, the ordinary shape, is therefore left naming nothing at all. It stays on whatever it was riding on and springs nothing for the rest of the scenario.

That empty link is what costs a house its victory when the tag was an [allow-win](/mapping/actions/taction-allowwin/#destroying-the-tag-instead) tag. The link is where the disposal reads the house to credit, so destroying the triggers first and the tag afterwards gives nothing back.

:::danger[An emptied tag is read through when a variable changes]
Every change to a global or a local variable walks the whole tag list and follows each tag's link, so that timed events tied to that variable can be restarted. The link is followed without testing whether it is still there. Once the disposal has taken the last trigger off a tag, the next change to any global or local variable reads through an empty link.
:::
