---
type: action
id: TACTION_CHANGE_HOUSE
title: Change House
summary: Transfers every active object attached to this trigger to the selected house.
valid_values:
  - A house available to the scenario.
caveats:
  - The action scans every infantry, vehicle, aircraft and structure whose tag is attached to the same trigger; it is not limited to the object that most recently sprang it.
  - Objects in limbo are skipped.
related:
  - type: action
    id: TACTION_ALL_CHANGE_HOUSE
---

## Behavior

The action walks every infantry, vehicle, aircraft and structure in the scenario, whatever kind of object sprang the trigger, and hands over each one that clears all of these, in this order:

1. It is active.
2. It has been put down on the map.
3. It is not in [limbo](/glossary/#limbo).
4. It has a tag.
5. That tag is attached to this trigger.

Each object that clears them changes hands with the selected house as the new owner, through the same capture path [an engineer walking into a structure](/systems/capture/) runs.

One firing can therefore transfer several separately tagged objects at once. The trigger has to be attached to an object-capable tag: with no tagged object anywhere in the scenario the sweep matches nothing and the action transfers nothing.
