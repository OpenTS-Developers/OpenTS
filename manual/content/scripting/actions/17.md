---
type: action
id: TACTION_REVEAL_SOME
title: Reveal around waypoint...
summary: Uncovers the ground around a waypoint for every human player, over a radius set by the trigger action, or by RevealTriggerRadius.
valid_values:
  - A scenario waypoint, read from the number field of the action line. The waypoint label at the end of the line is not used.
  - A number denoting the radius in cells. `0` falls back to `RevealTriggerRadius`.
  - A boolean determining whether to run a height-test. `0` runs the test; anything else skips it.
caveats:
  - A line whose number field is `0` reveals around waypoint `0`, whatever label ends the line. If the scenario places no waypoint `0`, the reveal is centered on a cell outside the playfield and uncovers nothing.
  - A radius field of `0` or less uses `RevealTriggerRadius` rather than a zero radius. A radius above `10` acts as `10`, the most any sight scan reaches.
  - The height-test switch leaves the height test on at `0` and skips it at any other value. Skipping reveals cells behind high ground as well. When the rules have `RevealByHeight=no`, the switch changes nothing.
  - The action does nothing for a player whose map is already marked as fully revealed by Reveal all map, the reveal team mission or the reveal crate. Reshrouding the map clears the mark.
related:
  - type: key
    id: RevealTriggerRadius
  - type: system
    id: map-visibility
  - type: action
    id: TACTION_REVEAL_ALL
  - type: action
    id: TACTION_REVEAL_ZONE
---

```ini title="map file"
[Actions]
DemoReveal=1,17,0,9,8,1,0,0,J ; trigger DemoReveal uncovers an 8-cell radius around waypoint 9, whose label is J, without the height test
DemoRadius=1,17,0,4,0,0,0,0,E ; trigger DemoRadius uses RevealTriggerRadius around waypoint 4, whose label is E
```

`9` and `4` are the waypoints the actions reveal around, and `J` and `E` are their labels. The `8` on the first line is the radius in cells, and the `1` that follows skips the height test. The second line leaves the radius and height-test fields at `0`, so it uses [`RevealTriggerRadius`](/keys/revealtriggerradius/) and leaves the [height test](/keys/revealbyheight/) on.

The reveal lifts both the shroud and the fog. [Map visibility](/systems/map-visibility/#reveals-granted-outright) compares this reveal with the others.
