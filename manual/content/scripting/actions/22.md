---
type: action
id: TACTION_FORCE_TRIGGER
title: Force Trigger
summary: Fires every trigger of the named type outright, without examining its events.
valid_values:
  - A trigger type the scenario declares. One trigger is built from it for each tag that holds it, and every one of those fires.
caveats:
  - A trigger already queued for destruction is refused, as a disabled one is.
  - The firing goes to the trigger and not to its tag, so the guard that stops a tag springing while it is already springing does not apply here.
related:

    id: TACTION_ENABLE_TRIGGER

---

[Reaching a trigger from another trigger](/systems/trigger-springing/#reaching-a-trigger-from-another-trigger) covers what forcing skips and what it leaves behind.

:::danger[A trigger that forces its own type never returns]
Ordinary springing cannot re-enter itself, because a tag refuses to spring while it is already springing. Forcing bypasses the tag and reaches the trigger directly, so that guard is not in the way. A trigger listing this action against its own type runs its whole action list again from inside itself, including this action, one level deeper each time. Nothing limits the depth and no condition ends the descent. Two trigger types that force each other do the same.
:::
