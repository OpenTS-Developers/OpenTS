---
type: action
id: TACTION_SET_GLOBAL
title: Global Set...
summary: Sets one of the scenario's fifty global variables.
valid_values:
  - A global variable number from 0 to 49. A number outside that range does nothing at all.
caveats:
  - Setting a global that is already set does nothing further. Everything the action produces beyond the stored value follows from the value changing, so a second firing on the same global raises no events and restarts no countdown.
  - A change that does happen is what admits the variable events to evaluation at all, and the mark it raises is one for the whole scenario rather than one per variable. While it stands, every tag on the general list is offered the global-set, global-clear, local-set and local-clear events alike. Each offer still tests the variable its own event names, so a trigger waiting on a different variable can fire on it only if that variable already stands in the state the trigger watches.
  - Changing a global also restarts the elapsed-time countdown of every trigger with an event naming that global, wherever in the scenario it sits.
  - The names come from the `[VariableNames]` section of the rules file rather than from a file of their own, and its entries are named with the global's number. Globals are passed across a campaign boundary into the next mission.
related:
