---
type: action
id: TACTION_PREFERRED_TARGET
title: Preferred target...
summary: Stores a target category on the trigger's house that nothing acts on.
valid_values:
  - Any quarry category. Every value behaves the same way, because nothing reads what is stored.
caveats:
  - The action runs and does nothing beyond the store. The category is written onto the trigger's house and no engine path reads it back.
  - Nothing about special weapon aiming reads it, and an attack team takes its category from the Attack line of its own script instead.
related:
  - type: enum
    id: QuarryType
  - type: mission
    id: TMISSION_ATTACK
  - type: system
