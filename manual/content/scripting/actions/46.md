---
type: action
id: TACTION_LOCK_INPUT
title: Lock input
summary: Hides the cursor and stops the mouse reaching the tactical view until something hands control back.
caveats:
  - The lock is read only where the tactical view takes the mouse. Presses over the map are dropped and the map stops scrolling. Nothing on the keyboard path reads it, and neither does the sidebar's own button handling, so a player who knows the layout can still act with the cursor hidden.
  - A band selection under way is abandoned as the lock goes on.
  - A structure waiting to be placed is dropped, and the repair, sell, power and waypoint modes are all cleared, before the lock takes hold. Control comes back with an ordinary cursor, whatever mode the player had selected when the lock went on.
  - EVA announces control on every firing, including one that finds input already locked. Firing it twice over the same lock still takes one unlock to release.
  - The lock is recorded on the scenario, so it survives the options screen and comes back when that screen closes. Winning, losing, restarting and aborting the mission each release it.
