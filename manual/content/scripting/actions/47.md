---
type: action
id: TACTION_UNLOCK_INPUT
title: Unlock input
summary: Brings the cursor back and lets the mouse reach the tactical view again.
caveats:
  - Everything typed while input was locked is thrown away as the lock comes off. A key held down through a scripted sequence does not act on it afterwards.
  - The action runs whether or not input was locked, and nothing is announced either way.
  - The cursor is brought back only where the scenario's own lock was set, and one hiding is undone. The zoom-in action hides the cursor without setting that lock, so a cursor hidden that way waits for the zoom-out action instead.
related:
  - type: action
    id: TACTION_LOCK_INPUT
  - type: action
    id: TACTION_ZOOM_OUT
---
