---
type: action
id: TACTION_REDUCE_TIBERIUM
title: Reduce Tiberium At...
summary: Strips the waypoint's own cell of Tiberium and leaves every cell around it exactly as it was.
valid_values:
  - A scenario waypoint. The action reads it from the waypoint number the line holds, not from the waypoint name at the end of the line.
caveats:
  - Nothing outside the waypoint's own cell is ever touched.
  - That one cell is reduced once for every cell lying within five of the waypoint, which is 109 reductions of a level apiece, so it is emptied however deep the Tiberium in it was.
  - Emptying a cell puts the eight cells around it back in line for a spread pass, so a field left with growth switched on closes the hole up on its own.
  - The number field is where the engine both reads this waypoint and writes it back, so the number a line holds there survives the engine writing the scenario out again. The name at the end of the line comes from a separate field, and the actions that read a waypoint from the end of the line use that field.
related:
  - type: system
    id: tiberium
  - type: action
    id: TACTION_TIB_GROWTH
---

```ini title="map file"
[Actions]
DemoThin=1,59,0,14,0,0,0,0,O ; trigger DemoThin empties waypoint 14, whose label is O
```

The number `14` is the waypoint whose cell the action empties. The trailing `O` is the same waypoint, written as its label.

A reduction takes one level off the cell. A reduction of a cell already at its lowest level takes the Tiberium away altogether, restores the cell's passability, and puts the eight cells around it back in line for a spread pass. Every reduction left in the pass then finds nothing there and does nothing.
