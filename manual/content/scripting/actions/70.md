---
type: action
id: TACTION_DESTROY_TAG
title: Destroy Tag
summary: Removes every tag of the named type and takes the triggers riding on it with them.
valid_values:
  - A tag type the scenario declares. Each tag built from it is removed, including the private tag a team makes for itself from that type.
caveats:
  - The tag is not released on the spot. The end-of-frame disposal takes it and the triggers riding on it in the same pass.
  - The action marks the tag for that disposal, and nothing else consults the mark. A marked tag goes on springing for the rest of the frame, and its triggers are not marked either, so they still fire.

## The disposal that clears a held victory

This is the one disposal that reliably gives an [allow-win](/mapping/actions/taction-allowwin/#destroying-the-tag-instead) blockage back. The triggers are still hanging off the tag when it goes, so the link the count is credited through is intact, whatever [lifetime](/systems/trigger-springing/#tag-lifetimes) the tag carried and however many triggers it held. That page owns the count and the two ways of losing it.
