---
type: action
id: TACTION_SET_AMBIENT_STEP
title: Set ambient step...
summary: Overwrites the ambient fade step in the loaded rules with a figure no map file can express.
valid_values:
  - No usable figure. The number on the line is taken as a whole number and then used as a fraction without being converted, so nothing written produces the value it names.
caveats:
  - A fraction such as `.1` is taken as the whole number `0` and stored as an exact zero. Any whole number is stored as a fraction too small to move the light level at all. Either way the fade steps by nothing from then on, so a level the mission asks the light to change to is never arrived at.
  - The overwrite is made on the loaded rules rather than on the scenario, so it outlives the trigger and applies to a storm's darkening as much as to a scripted change.
