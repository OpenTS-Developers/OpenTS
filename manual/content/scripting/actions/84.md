---
type: action
id: TACTION_WAKEUP_GROUP
title: Wakeup group...
summary: Puts every sleeping or harmless object of one numbered group onto guard.
valid_values:
  - A group number. A team type stamps its own group onto each member it takes, the Set Group ID action assigns one to the object that sprang the trigger, and the player's numbered team keys record one less than the key pressed. A row in `[Units]`, `[Infantry]` or `[Aircraft]` names one as well. An object that has never been given one sits at `-1`.
caveats:
  - The number is compared as it stands, so `0` names the group the player's own `1` key makes and not the ungrouped objects, which are on `-1`.
  - The sweep covers vehicles, infantry and aircraft only, so no structure is ever put back on guard.
  - Only the Sleep and Harmless missions are replaced, and destroyed objects and objects in limbo are passed over.
  - No house test is made. The group is matched across every house at once.
