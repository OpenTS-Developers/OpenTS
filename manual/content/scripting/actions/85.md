type: action
id: TACTION_VEIN_GROWTH
title: Vein growth...
summary: Writes the scenario's vein switch, which decides whether existing veins spread outward.
caveats:
  - Only the low part of the number is tested, so a figure of `256`, or any other multiple of it, reads as off while every other non-zero figure reads as on. The editor writes one or zero, so this shows only on a hand-written line.
  - The switch the action writes is the same one the map file sets, and the value stands from the moment the action runs until something else writes it.
