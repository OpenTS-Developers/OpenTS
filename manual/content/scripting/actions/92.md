---
type: action
id: TACTION_ACTIVATE_FIRESTORM
title: Activate Firestorm Defense
summary: Fires the trigger house's firestorm superweapon so that its firestorm walls come up.
caveats:
  - The wall is raised by firing the weapon rather than by being switched on, so the action does nothing at all when the wall is already up.
  - The house's own copy of the first firestorm superweapon in the declared list is the one fired. A rules tree that declares none leaves the action with nothing to fire.
  - For a house under human control the weapon has to have finished charging. Firing it while it is still charging changes nothing and spends nothing. Any other house raises the wall without waiting for the charge.
related:
  - type: system
    id: superweapons
  - type: action
    id: TACTION_DEACTIVATE_FIRESTORM
  - type: system
    id: laser-fences
---
