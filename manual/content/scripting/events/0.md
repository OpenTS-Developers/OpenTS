---
type: event
id: TEVENT_NONE
title: "-No Event-"
summary: Never satisfied, so a trigger with it never fires whatever its other events answer.
caveats:
  - The test answers no without looking at the offer, and no part of the game offers this event to anything in the first place.
  - Every event on a trigger has to be satisfied, so adding this one to a trigger that would otherwise work stops that trigger firing for the rest of the scenario.
  - The event describes no moment, so nothing about it is ever marked off. A persistent trigger re-examines it on every offer and gets the same answer.
  - The event places its tag on no list of its own. A tag whose triggers hold nothing else is offered nothing at all unless the map puts it on an object or a map cell. The offers it receives there are answered no.
  - A tag whose triggers never fire is never disposed of. Where such a trigger also holds Allow Win, the hold that action places on its house's victory stands for the rest of the game, and that house cannot win the mission.
  - Force Trigger runs a trigger's actions without examining its events at all, so it is the one way to get anything out of a trigger with this event.
related:

    id: trigger-springing

    id: TACTION_ALLOWWIN

    id: TEVENT_ANY
