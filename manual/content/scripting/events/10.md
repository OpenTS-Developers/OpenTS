---
type: event
id: TEVENT_BUILDINGS_DESTROYED
title: Destroyed, Buildings, All...
summary: Satisfied while the named house owns no structures.
valid_values:
  - A house the scenario declares. Naming a house the scenario does not contain leaves the test unrun, and the event is then satisfied by every offer.
caveats:
  - Structures marked `Insignificant=yes` are kept out of the tally, so a base left with only those satisfies the event.
  - A structure that undeploys into a vehicle is counted as a vehicle rather than as a structure, so one still standing does not hold the event off. The construction yard is exempt and stays a structure.
  - The tally follows ownership rather than presence on the map, and a structure in limbo still counts.
  - A house that owns no structures at the start of the scenario satisfies the event from the first frame.
  - The event describes a lasting condition, so a persistent tag holding it fires on every offer for as long as the house has no structures.
  - The event has nothing to ride on. Its tag joins the list of the trigger's own house, which adds nothing to the attachment total a semi-persistent tag waits on, so a trigger built on events of this kind needs a volatile or a persistent tag.
related:
  - type: system
    id: trigger-springing
  - type: event
    id: TEVENT_ALL_DESTROYED
  - type: key
    id: UndeploysInto
---
