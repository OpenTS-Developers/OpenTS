---
type: event
id: TEVENT_BUILD_INFANTRY
title: Build Infantry Type...
summary: Satisfied once the named infantry is the last one the trigger's own house finished producing.
valid_values:
  - An InfantryType. The record holds one type at a time. The comparison is therefore against the most recently finished soldier, not against a list of everything built.
caveats:
  - The record is never cleared, so the comparison holds from the moment the house finishes the named infantry until it finishes infantry of a different type.
  - Only the production path writes the record, so infantry that reaches the house any other way leaves it as it was.
  - This event is exempt from the requirement that an offer name it, which is why an offer about anything at all can satisfy it.
  - The event is remembered once it is satisfied, so a persistent tag holding it fires on every offer from the first one that matches onward, even after the record changes.
  - The event has nothing to ride on. Its tag joins the list of the trigger's own house, which adds nothing to the attachment total a semi-persistent tag waits on, so a trigger built on events of this kind needs a volatile or a persistent tag.
related:
  - type: system
    id: trigger-springing
  - type: system
    id: production
---
