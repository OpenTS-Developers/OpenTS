## Where the trigger sits and what it is offered

The event can only ride on a house, so its trigger is placed on the list the trigger's own house [polls once a frame](/systems/trigger-springing/#where-a-tag-is-offered-an-event). That poll names nothing in particular, and an event describing a moment needs an offer that names it. The poll therefore leaves this one unsatisfied every frame of the scenario. The one other offer that list receives names the attacked event.

## The mark it would read

The test the event would run is not about money. It asks whether the house the event names has been marked as robbed. The only thing that sets that mark is [losing a structure to an engineer](/systems/capture/#capturing-a-non-allied-structure). The mark is set on the house that lost the structure, and nothing clears it. An offer that did name this event would find it satisfied at any time after that house's first loss, rather than at the moment of one.
