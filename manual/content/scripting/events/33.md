## What has to happen

The event is offered when the local player selects the object and **all of** these hold, in this order:

1. the object is out of [limbo](/glossary/#limbo), is not already selected, and its type is [`Selectable=yes`](/keys/selectable/);
2. it is not a [loaner](/keys/landable/) that the player can currently move;
3. no structure is waiting to be placed on the map;
4. a house under the local player's control owns it;
5. selection responses are on, as described below.

An object of a computer house therefore never offers the event, and an object of another human player's house never offers it on this computer.

## Responses to a group selection

When one action selects several objects, the event is offered for each object that plays a selection response:

- A [band box](/systems/band-selection/) and the Select View hotkey offer the event for the first object they select only.
- The Select Team, Add Select Team, Add To Team and Center Team hotkeys offer it for the first team member they newly select only.
- The Select Same Type hotkey offers it for the first object of each type it adds.

Select Team always leaves selection responses off afterwards. Add Select Team and Add To Team leave them off when they newly select a team member. Until responses are turned back on, selecting an object by clicking it plays no response and offers nothing, and so does the next team hotkey.

These actions turn responses back on:

- issuing an order by clicking on the map;
- the Deploy Object and [Guard](/commands/guardobject/) hotkeys, when something is selected;
- a band box and the Select View hotkey;
- the Select Same Type hotkey, when the selection holds an object of the player's;
- the Center Team hotkey.
