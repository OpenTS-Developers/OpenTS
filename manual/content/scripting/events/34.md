---
type: event
id: TEVENT_NEAR_WAYPOINT
title: Comes near waypoint
summary: Satisfied when the tagged object finishes a move into a cell, or lands in one, within the distance set by ComesNearWaypointDistance.
valid_values:
  - A waypoint the scenario places. For a waypoint that is not placed, the result is unpredictable.
caveats:
  - The event is offered each time the object finishes moving into a cell, and when it lands after a parachute drop or a fall. An object that stands still near the waypoint, including one placed there when the scenario starts, does not satisfy the event until it moves.
  - Infantry and vehicles make the offer as they move. Aircraft do not.
  - The event is satisfied when the object is within [`ComesNearWaypointDistance`](/keys/comesnearwaypointdistance/) of the waypoint. The distance is measured in a straight line from the object's center to the center of the waypoint's cell, and height counts toward it. When the waypoint's cell lies under a bridge, or under one that has been destroyed, the distance is measured from the height of the bridge deck.
  - The event tests only the tagged object, whatever house owns it.
  - On a persistent tag, the event stays marked once it is satisfied. A persistent trigger holding only this event therefore fires on every later offer the tag receives, wherever the object has moved.
related:
  - type: system
    id: trigger-springing
  - type: key
    id: ComesNearWaypointDistance
---
