---
type: event
id: TEVENT_HOUSE_DISCOVERED
title: House Discovered...
summary: Satisfied once a human player other than the named house has discovered any object belonging to it, and from then on for the rest of the scenario.
valid_values:
  - A house the scenario declares. Naming a house the scenario does not contain leaves the test unrun, and the event is then satisfied by every offer.
caveats:
  - The mark is set the first time a human player other than that house discovers one of its objects. Nothing ever clears it, so the event stays satisfied from that moment.
  - Only a human player sets it. An object discovered by a computer house marks nothing. A human player's discovery of its own object marks nothing, so a house cannot discover itself.
  - The mark is set while the scenario is still being set up as well, so a house with an object standing inside the player's opening view is already discovered on the first frame.
  - Outside a campaign game every human player discovers every structure as it is placed. Every house that owns a structure is therefore discovered from the start of the scenario, except a human player with no other human player in the game.
  - The event describes a lasting condition, so a persistent tag holding it fires on every offer for the rest of the scenario.
  - The event has nothing to ride on. Its tag joins the list of the trigger's own house, and that adds nothing to the attachment total a semi-persistent tag waits on. A trigger built on events of this kind therefore needs a volatile or a persistent tag.
related:
  - type: system
    id: trigger-springing
  - type: system
    id: map-visibility
---
