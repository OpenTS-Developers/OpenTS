## The two announcements

[An electromagnetic pulse](/systems/emp-pulse/#what-a-pulse-reaches) springs the event on each object it takes, and that page settles which objects those are. Ordinary infantry are not among them; a [cyborg](/keys/cyborg/) is the only soldier a pulse reaches. An object whose type sets [`ImmuneToEMP=yes`](/keys/immunetoemp/) is not touched at all, and a limpet mine is destroyed instead of stunned. Both still spring the event.

A [`Webby=yes`](/keys/webby/) warhead springs the event on each soldier it pins, and on nothing else it lands on. [`IsWebImmune=yes`](/keys/iswebimmune/) skips the pinning altogether, so an immune soldier takes the hit as ordinary damage and springs nothing.
