---
type: event
id: TEVENT_LIMPED
title: Limped
summary: Fires when a weapon whose warhead sets a limpet factor attaches its firing house's mark to the tagged object.
caveats:
  - The attacking object's kind is never examined, and neither is the target's owner. Any weapon whose warhead sets a limpet factor above zero attaches the mark and springs the event.
  - The mark is kept one per house per object, so a house springs the event on a given object once. A second shot from the same house does nothing. It leaves no mark and springs nothing, and the firing object survives; the first shot removes the firing object.
  - Clearing the mark opens the event again. Healing the object, or a repair step at a service depot, clears it. The same house can then attach a fresh mark and spring the event a second time.
  - A structure, an aircraft and a soldier can all hold a mark, so the event is not confined to vehicles. Only a vehicle is slowed by one.
  - The event runs no test of its own.
related:
  - type: system
    id: trigger-springing
  - type: format
    id: scenario-triggers
  - type: key
    id: LimpetFactor
  - type: system
    id: repair
---

[`LimpetFactor`](/keys/limpetfactor/) on a warhead is the whole of the requirement. That page owns what a mark does to the object holding it, and what clears one. The limpet drone is only the shipped case. In the stock rules the drone deploys into a limpet mine, and that mine is the object that fires. Any other weapon whose warhead sets a limpet factor springs the event in the same way.
