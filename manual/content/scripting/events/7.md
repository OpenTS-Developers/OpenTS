type: event
id: TEVENT_DESTROYED
title: Destroyed by any house
summary: Fires when the tagged object is booked as a kill with an attacker credited for it, whatever house that attacker belongs to.
caveats:
  - The friendly fire exception does not exist. Nothing on the path compares the attacker's house with the object's, so a kill by an ally, or by another object of the same house, satisfies the event.
  - A death that credits no attacker springs nothing. Selling a structure, an object changing hands, a vehicle sinking and an aircraft an ion storm brings down are all booked with no attacker, so none of them reaches this event.
  - Being crushed does reach it. A crushable object run over by a vehicle is booked with that vehicle as the attacker. Cargo that dies with the transport carrying it is booked against whatever killed the transport, so it reaches the event only where the transport's own death would have.
  - Two removals are never booked as a kill at all, so this event cannot reach them — a soldier consumed walking into a structure or taking over a vehicle, and infantry or an aircraft standing on ice that gives way. The destroyed-by-anything forms are sprung directly at both.
  - A vehicle that has been taken over by infantry springs no destruction event when it later dies, provided the tag it is then holding is a transferable one.
