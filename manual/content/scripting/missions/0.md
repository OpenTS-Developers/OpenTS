  - "OnlyTargetHouseEnemy=yes on the TeamType narrows the search to the house's declared enemy. Nothing else about the team narrows it."
  - "The line runs again every turn. The team takes the next line on the first turn a pick finds no target of the category, or when every member that uses ammunition has run out."
