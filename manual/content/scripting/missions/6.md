---
type: mission
id: TMISSION_LOOP
title: 'Jump to line #'
summary: Continues the current team script from a selected one-based line number.
valid_values:
  - A one-based script line number; 1 jumps to the first line.
caveats:
  - A backward jump forms a loop with no automatic iteration limit.
  - The target must identify a populated line in the script's mission list. A number past the last line steps the cursor off the end, which deletes the team.
related: []
---

## Behavior

The mission rewrites the script cursor and marks the team ready for its next mission at once. It writes the number given less two, and stepping to that next mission adds one back, so the cursor ends one below the number given. That offset is why the number is one-based.

:::caution[A loop needs an external exit]
The loop mission does not count iterations or supply an exit condition. A trigger, team change, destruction, or another script mission must provide the way out when a permanent loop is not intended.
:::
